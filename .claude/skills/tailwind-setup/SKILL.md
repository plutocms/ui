# Tailwind CSS setup

This package ships no Tailwind CSS entry and registers no `css` option.

The app that uses Pluto owns the only Tailwind build of the app. Its CSS entry imports
`tailwindcss`, `@nuxt/ui`, and `#build/pluto.css`. See the `single-tailwind-build` skill in
`@plutocms/pluto` for the full rules.

Nuxt UI adds an `@source` for the `app/` dir of every layer. So the classes in this package's
components get generated by the app's build, with no setup here.

Do not add an `app/assets/css/tailwind.css` with `@import 'tailwindcss'` back to this package.
A second Tailwind build in a page overrides the utilities of the other build. That breaks the
responsive layout of the admin.

If this package needs its own tokens (`@theme`, `@custom-variant`, `@utility`), put them in
`app/assets/css/pluto-layer.css`. Do not import Tailwind there. Note: `#build/pluto.css` only
includes that file for an app that also extends `@plutocms/pluto`.
